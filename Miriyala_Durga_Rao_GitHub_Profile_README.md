## Representative Security Troubleshooting

My general approach to production security issues follows a consistent flow:

**Issue → Analysis → Action → Validation**

Representative scenarios I regularly work through:

- WAF blocking legitimate traffic — false-positive investigation and policy refinement
- API requests blocked by WAF — rule inspection, payload analysis, controlled exceptions
- HTTP 403 investigation — distinguishing WAF, CDN, and origin-side blocks
- CDN / origin connectivity issues — edge configuration and origin response validation
- DNS / TLS troubleshooting — certificate, handshake, and record-level analysis
- Zscaler access issues — forwarding, policy, and authentication-path validation
- Firewall rule conflicts — shadowed, redundant, and overly permissive rule review

*These are representative technical scenarios and do not describe any confidential employer incidents.*
